## Compile

With TeX Live (including the latex-extra and fonts-recommended collections),
from the repository root:

```sh
mkdir -p .reproduction/paper
cd paper
pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error -output-directory=../.reproduction/paper main.tex
pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error -output-directory=../.reproduction/paper main.tex
```

The output is `.reproduction/paper/main.pdf`. Hosted CI uses these commands and
retains the PDF, TeX log and numerical verification outputs as a workflow artifact.
A local alternative, from the repository root with Tectonic 0.17.0 installed:

```sh
mkdir -p .reproduction/paper
tectonic --untrusted --keep-logs --outdir .reproduction/paper paper/main.tex
```
